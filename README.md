# Great Books Reflection Portfolio

A personal website portfolio created for our Great Books course, showcasing critical analyses, personal insights, and reflections on timeless literary works from across world history.

## About the Project

This website serves as my final portfolio for the subject **Great Books (NRs)** under **Prof. Raquel Ballares**. 

As a fourth-year Computer Science student, this portfolio gave me a meaningful chance to step away from code and reflect on timeless stories. Through this project, I explored how ancient epics, fables, and classic tales from different cultures speak directly to human nature, personal values, and everyday struggles that we still face today.

## What is Inside the Portfolio

The website is divided into several main sections:

* **Home Page**: A welcoming introduction featuring an animated typewriter effect that introduces our journey through classic literature.
* **Student Profile**: A personal background sharing my reading journey, favorite topics, and expectations from the course.
* **Literary Analyses**: In-depth studies of seven timeless literary works, each examined through a different way of reading and understanding literature:
  1. *Voice out of the Whirlwind* (Ancient Hebrew Wisdom Tradition)
  2. *The Panchatantra* (Classical India)
  3. *The Ramayana* (Ancient Indian Epic)
  4. *The Mahabharata* (Ancient Indian Epic)
  5. *The Odyssey* (Ancient Greece)
  6. *The Song of Roland* (Medieval Europe)
  7. *The Tale of Genji* (Classical Japan)
* **Video Summaries**: Playable video summaries embedded directly inside each reading page, complete with creator credits to help visitors visualize each story.
* **Favorite Masterpiece**: A special feature spotlight on Homer's *The Iliad*, explaining why its honest look at human flaws, pride, and compassion resonated with me the most.
* **Course Reflection & Summary**: A concluding reflection summarizing core life lessons, memorable characters, and how studying these works changed the way I look at teamwork, empathy, and everyday decisions.

## Languages and Tools Used

To keep the website clean, fast, and easy to read, the following languages and tools were used:

* **HTML**: Used to structure the content, articles, and pages of the website.
* **CSS**: Used to style the website with an authentic classic library look, using warm paper tones, deep crimson red colors, and smooth animations.
* **TypeScript and JavaScript**: Used to organize the story data and power interactive elements, such as the animated typewriter text on the front page.
* **Astro**: The website framework used to combine all the pages and content into a fast, lightweight website.

## How to Run the Project Locally

If you want to view and run this website on your own computer:

1. **Make sure Node.js is installed on your computer.**
2. **Open your terminal or command prompt** in the project folder:
   ```bash
   cd greatbooks-reflection-portfolio
   ```
3. **Install the required packages**:
   ```bash
   npm install
   ```
4. **Start the local website**:
   ```bash
   npm run dev
   ```
5. **Open your web browser** and go to:
   ```
   http://localhost:4321
   ```
